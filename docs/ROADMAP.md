# Roadmap

## MVP / Phase 1
- [x] Go local web app and offline bilingual frontend
- [x] SQLite project, template, run and event storage
- [x] Basic Codex detection and opt-in npm installation
- [x] Codex exec JSONL logging, job cancellation, history
- [x] Prompt starter library and structured local prompt enhancement
- [x] Manual trusted Markdown source import with attribution
- [x] Installer recipes for Windows NSIS, macOS pkg and Linux deb
- [ ] Confirm CI builds and perform real installation smoke tests on each OS

## Phase 2
- [ ] Native desktop window (Wails), tray, OS notifications
- [ ] Interactive auth/setup wizard and packaged Node prerequisite flow
- [ ] Session resume by stable Codex thread ID
- [ ] Git worktrees, diff viewer, safe change approval and rollback
- [ ] Multiple concurrent isolated projects (per-project locks)
- [ ] Full-text search, pruning, redaction and encrypted backups
- [ ] Automatic scheduled source refresh (license/provenance review)
- [ ] Prompt refinement through Codex (separate read-only request)
- [ ] Per-project AGENTS.md inspector and conventions
- [ ] Token usage and costs where available in JSON events
- [ ] Plugin adapters for other agents

## Phase 3
- [ ] Agent orchestration, planner/reviewer/tester roles
- [ ] Policies, dependency graphs and observability
- [ ] Signed reproducible releases and automatic updates
