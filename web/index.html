راهنمای شروع سریع
مراحل نصب و کار با برنامه را به زبان انتخاب‌شده دنبال کنید.
MVP 0.1.x

    

     
۱
نصب برنامه
از GitHub Actions یک خروجی موفق را انتخاب و بسته مخصوص ویندوز (Setup)، لینوکس (deb) یا مک (pkg) را دریافت کنید. پس از اجرا، رابط در مرورگر باز می‌شود.

     
۲
نصب و ورود به Codex CLI
در «تنظیمات» وضعیت Node.js و npm را ببینید و در صورت آماده بودن، «نصب Codex CLI» را بزنید. سپس در ترمینال دستور codex login را اجرا و تنظیمات را بازخوانی کنید.

     
۳
افزودن پروژه
در «پروژه‌ها» نام و مسیر کامل پوشه موجود روی سیستم خود را ثبت کنید. برای مثال D:\dev\TavanHub. سپس پروژه را در داشبورد انتخاب کنید.

     
۴
نوشتن و اجرای درخواست
پرامپت را بنویسید؛ برای بررسی بدون ویرایش از read-only و برای اجازه ویرایش از workspace-write استفاده کنید. «تکمیل ساختاریافته» فقط یک قالب محلی به متن اضافه می‌کند. برای شروع روی «اجرای Codex» بزنید.

     
۵
تاریخچه و لاگ
خروجی اجرای فعلی در داشبورد و اجراهای گذشته در «تاریخچه اجرا» دیده می‌شوند. رویدادها در SQLite محلی ذخیره می‌شوند و مسیر فایل در تنظیمات مشخص است. لاگ‌ها ممکن است حاوی اطلاعات محرمانه باشند.

     
۶
کتابخانه پرامپت
از قالب‌های آماده استفاده کنید، متن دلخواه را ذخیره کنید یا فایل md/txt را با لینک مستقیم از GitHub وارد کنید. پرامپت‌های بیرونی قابل‌اعتماد فرض نمی‌شوند و باید قبل از استفاده بررسی شوند؛ گردآوری خودکار فعلاً موجود نیست.

     
نکته: در نسخه اولیه فقط یک اجرای همزمان پشتیبانی می‌شود. برای تغییر فایل‌ها ابتدا از پروژه Git Commit یا نسخه پشتیبان تهیه کنید. بسته‌های نصبی هنوز امضا نشده‌اند.

1
Install the application
Open a successful build at GitHub Actions, and download the Windows Setup, Linux deb, or macOS pkg artifact. Launch the app to open the local UI in your browser.

     
2
Install and sign in to Codex CLI
Check Node.js and npm in Settings, then choose Install Codex CLI when available. Run codex login in a terminal and refresh Settings once authentication is complete.

     
3
Add a project
Open Projects and enter a name and absolute path to an existing local folder, for example D:\dev\TavanHub. Select it from Dashboard afterward.

     
4
Run a prompt
Enter your request. Choose read-only for inspection or workspace-write to allow edits. Structure prompt appends a local template; it does not call another AI model. Click Run Codex to start.

     
5
View history and logs
Live events appear on Dashboard and previous runs under Run history. Events and status are stored in local SQLite, whose path is shown in Settings. Logs may include confidential source code or secrets.

     
6
Use the prompt library
Reuse starter templates, save your own or import direct Markdown/text links from GitHub. External prompts are untrusted and must be reviewed before use. Automatic source discovery is not yet supported.

     
Note: Only one run at a time is supported. Commit or back up work before enabling edits. Installer packages are not yet code-signed.
